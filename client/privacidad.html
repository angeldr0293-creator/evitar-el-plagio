Politica de privacidad

Esta politica explica que informacion recopila ZeroCopy IA y como se usa dentro de la plataforma.

Datos que podemos guardar

Podemos guardar nombre, correo, telefono, datos de cuenta, solicitudes, archivos enviados, entregas, historial de estados, registros tecnicos y datos relacionados con pagos, suscripciones y compras de creditos.

Uso de la informacion

Usamos estos datos para crear cuentas, gestionar solicitudes, asignar profesores, entregar revisiones, calcular creditos disponibles, proteger la plataforma, responder consultas y mantener registros basicos de actividad.

Pagos

Los pagos con PayPal se procesan mediante PayPal. La plataforma conserva referencias, estado de pago, plan o paquete comprado, fechas y datos necesarios para activar creditos o suscripciones.

Archivos

Los archivos se usan para prestar el servicio solicitado. No deben compartirse publicamente. Las descargas requieren sesion y permiso asociado a la solicitud.

Seguridad

Aplicamos controles basicos como sesiones, validacion de entradas, limites de intentos, descargas protegidas, validacion de creditos en servidor y registros de actividad critica.

Conservacion

Los datos pueden conservarse mientras la cuenta o la solicitud esten activas y durante el tiempo necesario para soporte, seguridad, cumplimiento operativo o respaldo.

Contacto

Para solicitar revision, correccion o eliminacion de datos, usa el formulario de soporte o escribe a soporte@zerocopyia.com.

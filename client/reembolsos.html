Política de reembolso

Esta política resume los criterios generales para solicitudes de devolución.

Cuándo puede aplicar

Puede evaluarse un reembolso si el pago fue duplicado, si no se inició el trabajo solicitado o si hubo un error operativo comprobable.

Cuándo puede no aplicar

Puede no aplicar si el trabajo ya fue iniciado o entregado, si el usuario envió información incorrecta, si cambió de opinión después de la entrega o si solicita un resultado contrario al uso permitido.

Revisión de casos

Cada solicitud se revisa según el estado del servicio, evidencia disponible, fecha de pago, alcance contratado y comunicación registrada.

Pagos pendientes

Cuando el pago sea manual, el servicio puede quedar pendiente hasta confirmar referencia o comprobante.
